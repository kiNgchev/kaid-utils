# Kaid-utils — is a modern toolkit for kotlin developers.

> [!WARNING]
> **LIBRARY IS UNDER DEVELOPMENT**

## Install
---
### Gradle (Kotlin)
Maven central repository
```kotlin
dependencies {
    implementation("net.kingchev.kaid:kaid-resource:{version}")
}
```

---
### Gradle (Groovy)
Maven central repository
```groovy
dependencies {
    implementation("net.kingchev.kaid:kaid-resource:{version}")
}
```
---
### Maven
Maven central repository
```xml
<dependency>
    <groupId>net.kingchev.kaid</groupId>
    <artifactId>kaid-resource</artifactId>
    <version>{version}</version>
</dependency>
```
